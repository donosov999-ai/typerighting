## Сделано и проверено

- Source-authoritative `src/kids.ts`: все33 уровня, 9RU/24EN, по5 слов, точный порядок и номера. Asset `assets/baseline/kids.json` генерируется `node flutter/tool/export_kids.mjs`; исходные kids/typing/keyboard SHA256 связаны с fixture и проверяются тестом.
- `domain/kids.dart`: word-by-word blocked input, Backspace игнорируется, Enter — неверный символ; физический bridge; 3 звезды без ошибок, 2 при `(1-errors/characters)>=.9`, иначе1. Это другая формула, чем accuracy других режимов. Доступ к уровню только после звезды предыдущего, повтор не понижает лучший результат. Нет WPM-цели ребёнку.
- `features/kids_page.dart` и main.dart: карта обеих языковых групп, все уровни; подсказка следующей клавиши, всегда видимая полная клавиатура, настоящий ввод, исходный кот (public/images/mascot.webp, копия без изменений). Локализованные исходные строки для7 языков интерфейса; учебный контент честно толькоRU/EN. Переход в AI использует текущий профиль.
- Atomic legacy `tr_kids` merge, максимум старых/новых звёзд, сохранение unknown/future IDs. Save failure держит итог/маршрут; retry идемпотентен. Не добавляет выдуманные скоростные результаты: source kids хранит звёзды, а не WPM/history.
- Auto-next3500ms только после сохранения, checkbox паузы, отмена при background/dispose/выходе. Enter/Space действует на result только с primary focus; сфокусированная checkbox сохраняет Space. Счётчик завершений живёт в parent KidsActivity, переживает выход/возврат в рамках запущенного приложения; мягкий отдых каждые3 уровня. Незавершённое слово/уровень не объявляется завершённым.

`design-acceptance/20261026-kids-candidate/{D2-map,J3-result}`: исходный reference sheet/crop, нетронутый actual, равная ширина, side-by-side, overlay50%, manifest/REPORT. Нельзя назвать его совпадением с устройством.

Нужны иллюстрированный маршрут карты, полноценная композиция результата/звёзд, явные действия отдыха и обычной практики, материалы/отступы/типографика. Native macOS только скомпилирован; запуск/ввод и реальные iOS/Android обновления без потери данных остаются отдельными проверками.
